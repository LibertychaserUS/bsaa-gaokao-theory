## 一、结构定理 / 子模性

1. **标题**：Optimal Search for the Best Alternative
   **作者+机构**：Martin L. Weitzman（哈佛大学）
   **年份/期刊号**：1979，*Econometrica* 47(3):641-654（JSTOR 1910412）
   **一句话主结果**：给每个盒子定义"预约值"(reservation value) 指标，按指标降序开箱、
   一旦某已开箱价值超过所有未开箱预约值即停，是独立价值下的**精确最优**策略（指标策略）。
   **与我方关联**：这是整条 Pandora's Box / value-index 谱系的**源头定理**，
   对应我方 LEMMAS.md A2（value-index 排序定理）与 A3（DP 精确性）里"v 降序=最优"这条结构的
   经济学原型；但 Weitzman 的模型允许"不开箱即拿默认值"与"开箱付费"，属非吸收、可放弃的搜索，
   与 BSAA 的**吸收**语义（一旦被录取/被开箱后续机会作废、且必须整表排序提交）不同——
   这是我方模型区别于经典 PB 的关键结构差异，措辞上不能说 BSAA "=" Weitzman 模型，只能说
   "同属指标策略家族、边界条件不同"。
   **链接**：JSTOR 1910412（未取全文，仅摘要/二手引用확인）

2. **标题**：Recent Developments in Pandora's Box Problem（综述）
   **作者+机构**：待核——WebSearch 片段未给出完整作者列表；搜索显示与 Hedyeh Beyhaghi
   （CMU）关联词频较高，但未见到明确的 "Authors: X, Y, Z" 署名行，**不排除误关联**，
   需人工登录 arxiv 页面核实。
   **年份/arXiv号**：2023，arXiv:2308.12242
   **一句话主结果**：系统整理 PB 问题近年扩展（非强制检视/相关性/在线学习/机制设计等分支）
   及其在市场设计、决策理论、机器学习中的应用。
   **与我方关联**：作为地图型综述，用于核对我方"复杂度地图"（无约束精确P / matroid (1-1/e) /
   异质成本 NP-hard）与近年扩展分支是否已被此综述收录，避免遗漏最新变体命名。
   **链接**：arxiv.org/abs/2308.12242v1（仅摘要/未取全文；作者「待核」）

3. **标题**：Pandora's Problem with Nonobligatory Inspection: Optimal Structure and a PTAS
   **作者+机构**：Hedyeh Beyhaghi（Carnegie Mellon University）、Linda Cai（Princeton University）
   **年份/期刊号**：arXiv:2212.01524；EC 2023（ACM，doi:10.1145/3564246.3585217）
   **一句话主结果**：在"非强制检视"（可不开箱直接选取，先验已知）变体下，刻画最优策略的
   结构（只需两条预先固定的开箱顺序之一），并给出 PTAS。
   **与我方关联**：这是**与 BSAA 不同的另一支 PB 变体**——非强制检视允许跳过检视成本直接选取，
   而 BSAA 要求录取前必须经历投档（检视是强制的、录取是吸收的）。用于在文献定位一节中
   明确排除混淆：我方吸收结构≠非强制检视结构，二者的"最优策略retains指标序"结论表面相似
   但机制假设不同，不可互相引用对方的精确最优定理作为己方证明。
   **链接**：arxiv.org/abs/2212.01524（摘要已读，含作者机构信息；正文未取）

4. **标题**：Pandora's Box Problem with Order Constraints
   **作者+机构**：Shant Boodaghians（UIUC）等，与 P. Fusco、S. Lazos、S. Leonardi 等合作
   （具体署名顺序及是否含 R. Reiffenhäuser 待核，WebSearch 片段未给出完整署名行）
   **年份/期刊号**：arXiv:2002.06968；发表于 *Mathematics of Operations Research*
   （moor.2022.1271，待核 DOI）
   **一句话主结果**：在开箱顺序受 matroid/图论约束的 PB 变体下，证明一般情形 **NP-hard**
   （精确解不可行，需近似算法）。
   **与我方关联**：直接对应我方 research_directions.md §1 复杂度地图中
   "一般 matroid 约束 → (1-1/e) continuous greedy" 与"无约束/常数配额 → 精确 P"的分界线，
   本文是该分界线（matroid 约束下退化为近似而非精确）在 PB 侧的**独立文献确认**——
   说明我方"配额 DP 精确、matroid 一般约束需近似"的复杂度地图不是我方孤立猜想，
   而与 PB 文献的顺序约束硬度结果方向一致。子模性在此文献中的使用方式：
   目标函数的子模性保证 (1-1/e) continuous greedy 的近似比，但**不能**绕开
   排序/约束交互带来的 NP-hardness——这与我方"子模性给出贪心近似保证，
   但配额约束下不能反推贪心精确最优"的论断（研究方向 §2-3 雷区④）完全吻合。
   **链接**：arxiv.org/abs/2002.06968（仅摘要/未取全文）

## 二、DP 精确 / Gittins 指标

6. **标题**：The Gittins Index: A Design Principle for Deciding When to Stop
   （原文题目待核，指代 2406.20062 "Pandora's Box with Correlations..." 或类似 Gittins-index-for-PB 工作）
   **作者+机构**：待核（WebSearch 片段确认主题为"用 Gittins 指标重新推导/推广 Pandora's Box
   精确最优策略"，未取得逐字作者行）
   **年份/arXiv号**：2024，arXiv:2406.20062
   **一句话主结果**：将经典 bandit/排队论中的 Gittins 指标概念应用于 Pandora's Box，
   证明（或重新证明）Gittins 指标给出独立价值情形下的**精确最优**开箱/停止策略，
   并可能推广到更一般的报酬结构。
   **与我方关联**：这是本次调研中**最直接命中"DP/指标给出精确最优"这条主线**的文献——
   与我方 LEMMAS.md A3（DP 精确性，Horner 分解递推 g(i,k)）在结论层面同属
   "序贯搜索问题存在多项式时间精确最优策略"这一类，但技术路径不同：
   Gittins 指标是**单调指标+停止阈值**的刻画方式（起源于可中断多臂老虎机的最优停止理论），
   我方是**显式状态转移 DP（剩余名额 k、剩余候选 i 两维状态）**的刻画方式——
   两者对独立 Bernoulli 情形应给出等价的最优值，但我方 DP 显式引入了"配额 k"这一维度
   （对应我方冲稳保硬约束场景），这在经典 Gittins-index-for-PB 文献中未见对应处理
   （Gittins 指标经典设定通常是单选或无配额约束）。**详见下方"文献定位"专节**。
   **链接**：arxiv.org/abs/2406.20062（仅摘要/未取全文，作者「待核」）

7. **标题**：Subset Selection for Maximizing Expected Order Statistics（ProbeMax 背景文献）
   **作者+机构**：待核完整署名（WebSearch 片段未返回逐字作者行，仅确认发表于
   NeurIPS 2020 Advances in Neural Information Processing Systems）
   **年份/期刊号**：2020，arXiv:2012.07935，NeurIPS 2020
   **一句话主结果**：研究从 n 个随机变量中选 k 个使期望最大值（或次大值）最大化的子集选择问题，
   给出算法与 PTAS/近似结果。
   **与我方关联**：对应我方 research_directions.md §1 "BSAA 是 ProbeMax/期望次序统计量
   （一般 PTAS，Mehta et al. 2020）的精确可解 Bernoulli 特例"这一定位陈述的**直接背书文献**——
   本文研究的正是"期望最大次序统计量"这一目标函数的一般（非 Bernoulli）版本，
   一般情形只有 PTAS 近似，而我方在 Bernoulli-吸收特例下用 DP 拿到精确解，
   是该一般问题族在特殊分布假设下的精确可解子案例，这条定位陈述在此文献确认下成立。
   **链接**：arxiv.org/abs/2012.07935（仅摘要/未取全文）

## 四、我们 DP 精确最优声明的文献定位

**核心结论（三句话）**：Weitzman (1979) 指标策略与近年 Gittins-index-for-PB 工作（2406.20062，待核作者）
已经确立"独立价值下 Pandora's Box **存在**精确最优的多项式时间策略"这一**结论层面**的事实，
这不是新发现；但这些经典/近年结果针对的是**非吸收、可放弃、通常无配额约束**的经典 PB
（开箱后可选择拿走或放弃继续搜索），而我方 BSAA 是**吸收结构+强制排序提交+可选配额约束**的变体
（Chade & Smith 2006 college-application-portfolio 谱系），二者除结论相似外机制假设不同，
**据此我方的定位应改为**："在吸收结构（一次性提交排序表、录取即终止）这一变体下，
精确最优可由 Horner 分解 DP 达成"是我方论文的一个**局部新贡献**（把已知的"经济学重发现"
——即 research_directions.md §1 已经承认的"在高考语境重新发现并精确化经典结果"——
坐实到吸收+配额这一具体子结构上），而不是"序贯搜索问题存在精确解"这一**大结论**本身的
首次发现。具体分三层措辞建议：

1. **已知、不可声称首次**：「序贯搜索/Pandora's Box 存在多项式时间精确最优策略」——
   这一命题本身由 Weitzman (1979) 奠基，Gittins-index 文献（2406.20062，待核）从另一角度
   重新推导/推广。我方论文措辞不能写"我们首次证明序贯搜索可精确求解"。

2. **可能是新的、但需与 2406.20062 全文比对才能确认**：我方 A3 的**配额维**DP
   （状态含"剩余名额 k"这一维，用于处理冲稳保≥q个p≥0.8这类**硬配额约束**）
   在经典 Weitzman 指标策略与目前找到的 Gittins-index-for-PB 摘要描述中**均未见提及**
   （经典 PB 通常是"选1个"或"无约束选若干个都不放弃"的设定，未见"选恰好k个/至少k个满足某条件"
   这种带基数约束的精确 DP 表述）。**但这仅基于摘要判断**——2406.20062 全文究竟是否处理了
   配额/基数约束扩展，必须取得全文核实后才能下最终结论，当前只能标注"初步判断为局部新意，
   置信度中等，需全文核查"。

3. **明确的新贡献（不依赖上述文献比对即可确立）**：把 DP 精确解与
   (a) 我方 LEMMAS A2 的 distribution-free 逐点排序论证、
   (b) LEMMAS A4 Fréchet 最坏情形安全界、
   (c) 混合不确定-随机模型 B2/B3（价值端为专家不确定变量、录取端为频率概率的折叠定理）
   三者组合成一个**统一的证明链**，并用 Lean 4 机器验证 A1-A3/B0-B3 零 sorry ——
   这一"机器验证的统一证明链 + 吸收/配额扩展 + uncertain-random 混合折叠"的**组合**，
   在当前调研范围内**未见任何 PB 文献做到**，这是可以放心声称的新意所在，
   且不依赖对 2406.20062 全文的进一步核实即可成立（因为其他 PB 文献即便有精确 DP 结论，
   均未见与 Liu 不确定统计的折叠定理相结合）。

**行动建议**：论文措辞应避免"我们首次证明 XX 存在精确解"这类大字报式表述，
改为"在吸收+配额约束这一具体变体下给出显式 DP 构造，并将其与分布无关的排序论证、
Fréchet 安全界、以及 uncertain-random 混合价值折叠定理组合成统一证明链（Lean 4 验证）"。
