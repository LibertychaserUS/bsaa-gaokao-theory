## 理论轨 · 数学侧验收（MATH 门）

- **MATH1 定理台账（无隐性猜想原则）**：管线与论文用到的每条数学命题分级登记：
  `lean`（机器验证：A1/A2/A3/B2/B3 现役）/ `proved+oracle`（手证+数值 oracle 验证）/
  `cited`（文献结论，带精确出处：Chade-Smith 2006 等）/ `conjecture`（猜想）。
  **load-bearing 集合（管线实际依赖的）必须零 conjecture**——例：贪心精确性是猜想
  ⇒ 上线优化器只用 DP（A3 已 Lean 证），贪心仅作性能对照。
- **MATH2 Lean 回归门**：`formal/` 全量编译零 sorry；公理集 ⊆ {propext, Classical.choice,
  Quot.sound}（axiom-check 脚本），每次理论轨 commit 必跑。
- **MATH3 前提-现实映射表**：每条定理的前提逐一映射到山东现实：
  原子性（无调剂）→ 专业+院校模式成立✓；录取独立性→ 不成立，缓解=Fréchet 最坏界 +
  因子模型章（限定口径声明）；v 与录取事件可分→ B2 吸收结构成立✓。
  状态枚举 `holds / violated-mitigated / violated-declared`，出现未声明的 violated = 红。
- **MATH4 陈述-实现对应**：每条有代码对应物的定理配对应测试（同输入，Lean 定义
  与实现输出逐点相等；DP g ↔ 实现 g、Horner U ↔ 期望模拟）——沿用仓内 15 条定理
  试验的模式并扩到混合模型（B2/B3 数值对应）。
- **MATH5 oracle 规模底线**：load-bearing 定理的数值验证 ≥ 5000 实例且必含对抗族
  （tie 值、p∈{0,1}、v 碰撞、极端 k）；现有 DP 8000 实例零失配为基线，回归不得缩水。

## 理论轨 · 算法侧验收（ALG 门）

- **ALG1 oracle 等价**：DP 与暴力枚举在 n≤12 全族对拍（≥5000 实例含对抗族）零失配；
  配额 DP 同标准（现有 814 实例基线只增不减）。
- **ALG2 不变量套件**：g(L,k) 对 k 单调不减；0 ≤ U(S) ≤ max v；配额 DP 只返回可行组合；
  v 降序排序后 U 不劣于任何其他排序（A2 抽样验证）。违反任一 = 红。
- **ALG3 贪心对照（非依赖）**：GSIO vs DP 的 utility gap 全量记录（预期 ~0）；
  gap>EPSILON 的实例入库作猜想研究素材——但**任何管线路径不得假设 gap=0**。
- **ALG4 性能门（普通批真实规模）**：DP 在 2000 候选 × 96 志愿位 ≤ 100ms（现测 1ms，
  余量 100×）；无指数回退路径；内存 O(Nn) 有界。
- **ALG5 确定性**：tie-break 规则显式成文（EPSILON 语义、同分序），同输入 → 逐字节同输出。
- **ALG6 边界完备**：空表 / 全 p=0 / 全 p=1 / k=0 / k>N / 单候选 全部有定义输出，零 crash/NaN。

## 设计法则 · 复杂度外置（问卷侧；Oliver 2026-07-16 指令）

**核心算法只关注最重要的（p, v, k, 配额）；一切资格性约束外置为"问卷 → 过滤"层。**
性别限制（只招女生）、色盲色弱、外语语种、面试政审、单科成绩、专项资格、体检结论等
硬约束**永不进入优化内核**——它们是候选宇宙的**集合过滤谓词**：
`合格宇宙(学生) = {c : ∀ 谓词 P_c, P_c(学生问卷) = true}`，算法在过滤后宇宙上原样运行。
数学上免费：A2/A3/B2/B3 对任意候选子列表逐字成立（MATH3 增记 `filter-invariance: holds`）。

配套三件（登记为 v2 建设项，不阻塞 7/22 冻结线——冻结的是阈值预测，不涉资格过滤）：

  predicate_type, predicate_value)`——从已提取的 annotations_json 派生（谓词类型枚举：
  gender / color_vision / language / interview_政审 / single_subject / 专项资格 / 体检），零新解析成本。

  ②偏好价值（A6 已定：v_dead、组内着陆价值、"绝不接受"清单）③风险态度（B6 边界内凹效用参数）。

- **L5 越权清单（loop 内禁止，必须问 Oliver）**：git push；删除/改写 R 区或 L 区任何文件；
  放宽任何门；改变实验范围（增省/增类别）；对外发布任何内容。
- **L6 进度可见**：每完成一个阶段，主循环向 Oliver 发一段简报（阶段、门禁结果、下一步、

## ALG 门覆盖缺口 (主循环独立核验 theory-gates 时发现, 2026-07-16)
- **现状**：alg_gates.mjs 的 ALG1 oracle 等价用的是脚本内**复刻的 DP** vs 暴力枚举——验证的是"DP 递推实现正确"，
  **未验证生产求解器**。生产代码是 src/domain/paperTheory.ts 的 `greedySubmodularOptimization`（GSIO 贪心）+
  `bruteForceOptimal`，两者均为纯内存数组接口 (PaperCandidate[], capacity, pi)，**不依赖 DB，可用合成候选独立测**。
- **应补门 ALG1c (生产求解器 oracle 等价)**：import dist/src/domain/paperTheory.js 的生产 greedy 与 bruteForce，
  在合成候选上对比 —— 但这里验证的是**效用近似比**（GSIO 是贪心，非精确），不是逐字节相等。
  formal/experiments/dp_vs_gsio_real.mjs 已在真实黑龙江实例上跑过：DP−GSIO=1.67e-9（效用近乎相等）但
  **集合重叠仅 26/45**——印证 §2"近优大平台期"（目标在最优附近极平，多组合近最优）。
  ⚠️ dp_vs_gsio_real.mjs 用 data/gaokao.bsaa.sqlite（**L区污染，含 estimated_rank_2025**）+黑龙江旧数据，
  **禁止进门禁**（跨区红线）。ALG1c 必须用合成候选，不碰任何 R/L 区真实数据。
- **性质**：这是"验证覆盖面"缺口非正确性缺陷——已证的是 DP 实现对 + 生产 GSIO 在真实实例上近最优；
  缺的是把"生产 GSIO 近似比"做成可重复门。不阻塞当前理论轨（MATH 全绿+ALG 复刻DP全绿），登记为 ALG 门增强项。
