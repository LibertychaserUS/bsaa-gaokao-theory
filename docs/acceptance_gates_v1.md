## Stage 2 校准验收（C 门）

分三层：**结构硬门**（违反=代码错误）、**基线相对门**（不过=模型无存在价值）、
**报告项**（无阈值，如实记录进论文）。

结构硬门：
- **C1 无泄漏审计**：训练特征矩阵逐列带"官方发布日期"标签；对预测年 Y 的任何特征，
  发布日期 < Y 年志愿填报截止。审计脚本输出逐列判定表，一列红即停。
  特别地：estimated_rank_2025 及 L 区（legacy 库）任何衍生量**出现即失败**。
- **C2 年对掩码生效**：训练样本对照 §7.10 掩码——受选科断层影响的（理工农医×2023→2024）
  样本对零使用（或仅以显式 regime flag 进入且在报告中单列）；机器抽查 100 对验证。
- **C3 删失点处理**：censor=le/missing 的行不进点估计残差池；删失似然或显式剔除，
  处理方式在构建元数据中声明。"前50名"行出现在普通残差池 = 失败。
- **C4 可复现**：固定种子重跑，全部系数/预测摘要一致（与 G8 同标准）。

基线相对门（留一年回测，测试年=2025）：
- **C5 打不过就不上**：预设基线 B0=去年位次直接搬运（carry-forward）、
  B1=近三年线性外推。我方模型的位次点预测 MAE（百分位尺度）与 CRPS **必须两项都 ≤ B0**；
  打不过 B0 则回炉，禁止带病冻结。
- **C6 区间校准有效**：名义 90% 预测区间的实际覆盖率 ∈ [85%, 95%]（percentile 尺度，
  按 |去年-今年位次漂移| 分层后每层也不得低于 80%）——这是"校准"二字的定义性检验。

报告项（记录不设门）：Brier/log-loss、Murphy 分解、CORP 可靠性图、sharpness、
按计划变动分层的误差、新设专业（unmatched）占比与处理方式。

## Loop 治理（L 规则）

- **L1 串联**：A→G→C→F→R 顺序闭环，跨阶段并行仅限"下一阶段的纯准备工作"（写脚本骨架）。
- **L2 失败即停**：任何门红 = 该 loop 分支停止 + 向 Oliver 报告（不自行放宽/绕过/重试到过为止）。
- **L3 commit 边界**：每阶段全绿 = 一个 commit（阶段名进 message）；中间产物不散落。
- **L4 子代理纪律**：一切子 agent 显式 model（fable/sonnet）；返回值纯文本，
  结构化副产物走文件；主循环**亲自复验**子代理产物（跑门禁+抽查），不采信自报全绿。
- **L5 越权清单（loop 内禁止，必须问 Oliver）**：git push；删除/改写 R 区或 L 区任何文件；
  放宽任何门；改变实验范围（增省/增类别）；对外发布任何内容。
- **L6 进度可见**：每完成一个阶段，主循环向 Oliver 发一段简报（阶段、门禁结果、下一步、
  异常清单）——全自动 ≠ 静默。
