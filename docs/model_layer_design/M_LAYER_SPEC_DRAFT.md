## 1. M 区定位

```
L 区（污染隔离，只读封存）
R 区（原始不可变，sha256 锚定）
D 区（清洗事实层：T1-T5 + 删失标记，忠实原文）    ← 已完成，主循环独立核验
      │
      │  ← 你在这里问的问题：删失标记=信息被隐藏的坐标，不能直接喂算法
      ▼
M 区（建模输入层）：把 D 区的删失标记诚实转译为算法可用的统计构造
      │
      ▼
算法（BSAA/DP 精确求解器）：吃 (候选(p,v)列表, k, 冲稳保配额)
```

**为什么清洗完不能直接用**（这是 M 区存在的全部理由）：D 区每一个 `censor` 标记都是"信息被隐藏的坐标"，直接喂算法会犯两类致命错——
1. **把区间界当点值**：`le=50`（清华"前50"）真值在 [1,50] 未知，当 50 用会系统性高估该项目位次、低估其严格度，导致边缘考生 p_i 虚高；T2 头部聚合哨兵的 gap 人数位次是区间 [1,gap]，当点值会捏造精度。
2. **把不同总体混为一谈**：`missing` 里"投档未满（弱门槛）"与"真缺失"语义相反，统一 impute 会让两个方向的偏差互相掩盖；征集轮（round2/3）是被自选择截断的子总体，池化进主线阈值史 = 幸存者偏差。

M 区的职责边界：**输入=D 区事实表 + 删失标记 + 问卷侧硬约束；输出=已资格过滤、已归一化、带不确定性的候选 (p_i, v_i) 列表**。资格谓词（性别/色觉/语种/单科…）在 M 区做过滤后即消失，不作为字段传给求解器（ALG7 内核纯净性）。

## 2. 分层派生阶段（M1–M5 建模阶段，与清洗 M1-M5 匹配阶段区分：这里用 MB 前缀）

> 记号避撞：清洗规范已有实体匹配 M1-M5、红队备忘提议模型门 MDL 系列。本节建模阶段用 **MB**（Model-Build）前缀。

| 阶段 | 名称 | 输入 | 输出 | 关键约束 |
|---|---|---|---|---|
| **MB1** | 位次归一化 | T1 min_rank + T2 一分一段 N_total | 池内百分位 `u=(rank−0.5)/N_total`（Hazen 修正） | head_aggregate 位次侧免疫、分数侧反查返回**区间**；跨年可比靠百分位不靠位次差 |
| **MB2** | 阈值史拼接 | T5 xwalk + MB1 百分位 | 每 entity 的 `(year, u, u_type)` 时间序列 | M1/M2 同权拼接；M3 按 match_confidence 降权展宽方差；unmatched 分"新设/停招"两路 |
| **MB3** | 删失感知的 G_p 估计 | MB2 阈值史 + censor 标记 | 阈值分布 `G_p(·;θ)` + 录取概率 `p_i=1−G_p(R;θ)` | le→左删失似然 `G_p(50;θ)`；missing→分流；征集轮→分层不池化；**删失点绝不进点估计残差池** |
| **MB4** | 供给/资格/价值装配 | D 区 identity 注记 + 问卷 + T3/T4 + 2026 lag-proxy | 资格过滤后的候选宇宙 + v_i + 冲稳保配额 | 资格谓词外置过滤；2026 供给用带不确定性标签的 lag-proxy；v_dead 定义见开放问题 A5 |
| **MB5** | 算法输入契约打包 | MB1-4 全部 | `(候选[{id,p_i,v_i}], k, 配额q)` | 对齐 DP（非贪心）签名；NaN/Inf 在契约层拒绝；p_i 带置信带 |

## 3. 隐藏信息处理总表（合并视角2/3，M 区的技术核心）

| 删失位点 | 隐藏了什么 | 诚实统计构造 | 进入阶段 | 误用后果 |
|---|---|---|---|---|
| **T2 head_aggregate**（顶部聚合哨兵，count=gap） | [s+1, table_top] 区间内逐分人数分布；落此区间候选真实位次仅知 [1,gap] | 位次输出**区间** [1,gap]，禁塌缩点值；密度 f 该段用 EVT（广义 Pareto）尾部外推或声明"该段区间自动放宽" | MB1（分数侧反查）、MB3（f 估计） | 副科池（政/史/地）聚合区宽达 15+ 分，误用点值使顶尖副科考生位次精度虚高 |
| **T1 `le`**（清华前50） | 真实阈值 ∈ [1,50]，只知上界 | 左删失似然 `L=G_p(50;θ)` 进 MLE，绝不当精确值 | MB3 | 当 50 用 → 系统性低估该项目严格度 → 边缘考生 p_i 虚高 |
| **T1 `missing`-投档未满** | "无阈值"这一事实（阈值概念不适用） | 结构性缺失，不进阈值拟合；建 `unmet_demand_flag`；p_i 用 T4 控制线代理≈1，显式标注"控制线代理非自身阈值" | MB3、MB4 | 当"松阈值"套连续模型 → 虚假精度 |
| **T1 `missing`-真缺失** | 连"是否存在阈值"都未知 | 排除出拟合；若落 2026 目标集，退到 xwalk 跨年回填或同类分层均值，显式标"backfilled/低置信"、区间放宽 | MB3 | 统一 impute → 与投档未满的反向偏差互相掩盖 |
| **征集轮 round2/3** | 数值精确但所指总体被自选择截断 | 不池化进主线；round=1 为主线唯一校准源；round2/3 仅作"曾征集"二元哨兵或独立分层 | MB2、MB4 | 池化 = 幸存者偏差（雷8）实体版 |
| **联合选科池（物+化）** | 真实联合分布不可得 | 逐阈值 Fréchet 界给**区间**，不假设独立点估计；下界退化为0时上界不可估须声明 | MB1 | 假设独立 → 联合池百分位虚假精度 |

## 4. 算法输入契约（合并视角1）

**M 区→求解器的最终接口**（对齐 DP 精确求解器，非 GSIO 贪心——LEMMAS A3 + MATH1 定 DP 为唯一合法上线求解器）：

```
solve(candidates: {id: string, p: number∈[0,1], v: number≥0}[],
      k: number∈[0,N],           // 志愿容量
      quota?: {threshold: number∈[0,1], q: number})  // 冲稳保配额，阈值参数化（禁沿用脚本硬编码0.8）
  → { order: string[], expectedUtility: number }
```

契约层铁律：
- **排序是契约前置步骤**（v 降序），不是求解器可选项（A2/A3 依赖）。
- **NaN/Inf 在契约层拒绝或显式标记**，不传给求解器靠边界完备性"意外兜住"。
- **资格谓词不是字段**：`合格宇宙 = {c : ∀ 谓词 P_c, P_c(问卷)=true}`，过滤后从契约消失（ALG7）。
- p_i 若来自删失/回填，**带置信带**，不与真实观测同权呈现。
