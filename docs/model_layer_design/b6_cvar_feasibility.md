# B6 开放问题 × Ji one-hot 归约：可行性评估（纸上推导，非形式化证明）

> 理论攻坚 agent，2026-07-16。任务：评估 Jingwei Ji（Stanford, arXiv:2605.19181）的
> one-hot + Rockafellar-Uryasev 归约能否攻下 `formal/LEMMAS.md` B6 边界声明中的开放问题
> （CVaR/分位数型准则在整表 Y 的 Ch 分布上不可线性折叠）。
> 依据：LEMMAS.md（A1-A3, B0-B6）、`docs/literature/lit_cvar_pandora.md`（Ji 全文级摘要）、
> `docs/research_directions_2026-07-15.md` §5/§7.5/§7.6。
> **本文档是可行性判定 + 纸上推导链，不是机器验证的证明；所有"可证"判断均为人工评估。**

## 1. 判定结论

**能走通。** BSAA 的吸收结构（每次实现至多一个候选兑付）正是 Ji one-hot 恒等式的实例
（准确说是 *at-most-one-hot*，全滑档事件补 0，由 t ≥ 0 无害吸收）。经 R-U 变分 + one-hot
拆解，**CVaR 最优化精确归约为有限格点 T 上的一族风险中性 BSAA 子问题 + 外层对 t 的有限搜索**，
每个子问题原样使用 A2 排序 + A3 DP。需补约 6 个新引理（B7a-e + 主定理 B7，全部有限代数、
零实分析，可证性高；精确陈述见 §4），外加 1 个负向引理（单标量折叠不可能——B6 原判断的
"不可折叠"部分**仍然为真**，被精确化而非推翻）。

B6 因此从"开放/不可分离"改写为：

> **CVaR 无单标量折叠（反例可证），但存在精确的一维线性族归约：**
> `max_x CVaR_α^Ch(Y_x) = max_{t∈T} { (1/α)·OPT_BSAA(ṽ(t)) − ((1−α)/α)·t }`，
> 其中 `ṽ_c(t) = E_M[min{t, V_c}]`，`T = {0} ∪ ⋃_c supp(V_c)` 为有限格点。
> 代价：计算量乘 |T| 因子；结构代价：最优排序依赖 t*（即依赖 α 与全局实例），
> "单指标排序"表述在不确定值情形下不可恢复。

意外收获（推导副产品）：同一 mixture 结构使 **VaR 最大化**（水平集扫描,B8）与
**机会目标最大化 max Ch{Y ≥ v₀}**（直接线性折叠,B9）也精确可解——B6 边界声明中的
三兄弟（CVaR/分位数/机会约束）里只有 **ε-约束形式**（max E s.t. Ch ≥ β，双目标）仍然开放。

## 2. 纸上推导链

### 2.0 约定与准则定义（必须先钉死）

- 有限支撑、纯代数，K 为线性序域，α ∈ K，0 < α ≤ 1（与 LEMMAS 全局约束一致）。
- 报酬型（下尾）CVaR：`CVaR_α(Y) := 最差 α 质量的平均`。R-U 变分形式（等价，两写法恒等）：
  `CVaR_α(Y) = sup_t { t − (1/α)·E[(t−Y)⁺] } = sup_t { (1/α)·E[min{t,Y}] − ((1−α)/α)·t }`。
  恒等验证：`min{t,Y} = t − (t−Y)⁺` 代入即得。α=1 退化为 E[Y]（sup 在 t=max supp 取得）。
- **混合情形准则定义钉死为**：Y 的 chance 分布 `Φ(y) := Ch{Y ≤ y} = Σ_ω w(ω)·M{γ: Y(ω,γ) ≤ y}`
  （Liu 链式，概率在外层——即 B2'/雷6 已登记的建模公理），CVaR^Ch 定义在 Φ 上。
  B6 原文"对整表 Y 的 Ch 分布非线性"正是这个定义，口径一致。
  **形式化建议**：直接以有限 R-U sup 形式为定义（`max_{t∈T}` 有限格点），
  "= Φ 的下尾平均"作为解释性引理（B7a），绕开分位数的测度论细节。

### 2.1 Q1：R-U + one-hot 拆解是否成立 —— 成立，含全滑档事件的处理

固定方案 x = (S, σ)。逐实现 ω：`Y_x(ω) = Σ_c A_c(ω)·v_c`，其中
`A_c(ω) = 𝟙[firstAdmitted(x,ω) = c]` 是 **at-most-one-hot**（全滑档时全零，Y=0）。

**关键恒等式（B7b）**：对 t ≥ 0、v_c ≥ 0、A at-most-one-hot：
`min{t, Σ_c A_c v_c} = Σ_c A_c·min{t, v_c}`。
- A one-hot 于 c：两边都是 min{t, v_c}。✓
- A 全零：左 = min{t,0} = 0（**需 t ≥ 0**），右 = 0。✓
- 这里比 Ji 的严格 one-hot 多出全零分支——t ≥ 0 是无害限制，因为 Y ≥ 0 时
  `h(t) = t − (1/α)E[(t−Y)⁺]` 在 t ≤ 0 上 = t ≤ 0 ≤ CVaR_α(Y)，sup 必在 t ≥ 0 达到。

等价视角（值得写进论文，一行）：`min{t, max_{c∈A(ω)∩S} v_c} = max_{c∈A(ω)∩S} min{t, v_c}`
（单调变换与 max 交换）——即**截断直接作用在候选值上，嵌套 coverage 结构（§1 layer-cake）原封不动**。
这是本归约逃逸 Maehara 硬度的结构根源（见 §3 卡点 8）。

于是对确定值：`E[min{t, Y_x}] = E[payoff of x under values v^t]`，`v_c^t := min{t, v_c}`——
**逐 ω 精确相等**（不只是期望相等），故对任意录取联合分布都成立。

### 2.2 Q2：内层排序/DP 结构是否逐点保持 —— 确定值：是，且比 Ji 更强；不确定值：逐 t 保持

**确定值情形（强结果）**：`min{t,·}` 单调不减 ⇒ v 降序 ⇒ v^t 降序，对**所有 t 同时**成立。
A2 是逐点定理：对每个 ω，v^t 降序的 payoff = `max_{admitted∩S} v^t` ≥ 任何其他排序。
所以对固定 S：
1. v 降序 σ* 使 `E[min{t, Y}]` 对每个 t 同时最大 ⇒ `CVaR_α(Y_{S,σ*}) ≥ CVaR_α(Y_{S,σ})`；
2. 更强：A2 本身给出 `Y_{S,σ*}(ω) ≥ Y_{S,σ}(ω)` 逐点占优 ⇒ **任何单调、律不变的风险泛函**
   （CVaR、VaR、任意 distortion、任意 EU）下 v 降序都最优，**且 distribution-free**
   （任意录取联合分布）。
   ——即：**排序层从来不是 B6 的真障碍；A2 的逐点性免费升级到全部单调准则。**
   B6 的真障碍在选择层（选哪个 S）与价值折叠层（不确定 V_c）。

**选择层**：固定 t，内层 `max_x U(x; v^t)` 就是一个标准 BSAA 实例（值 v^t ≥ 0），
A3 DP 精确（同一 v 降序列表 L 对所有 t 通用，只换值）。配额版走配额 DP（继承其证明状态，见 §3 卡点 2）。

**sup 交换**：`max_x sup_t h(x,t) = sup_t max_x h(x,t)` 是联合上确界的平凡交换。
BSAA 方案是事前承诺的静态列表（非 Ji 的自适应策略），这一步比 Ji **更简单**，无策略可测性问题。

**外层有限性（精确、非数值搜索）**：每个 `h(x,·)` 是 t 的凹分片线性函数，折点 ⊆ T := {0} ∪ {v_c}。
在 T 的相邻格点之间每个 h(x,·) 都是仿射的 ⇒ `φ(t) = max_x h(x,t)` 在每个格胞内是有限个仿射函数
的 max = 凸的 ⇒ 胞内最大值在端点取得 ⇒ **全局最优 t* ∈ T**。
（注意：φ 整体非凹非凸，"凹函数的 max"不保凹——但胞内凸性足够，这一步是格点精确性的正确论证，
不能只说"凹函数折点处取 max"。）

**不确定值情形**：`ṽ_c(t) := E_M[min{t, V_c}]` 逐 t 折叠（见 2.3），
但 **ṽ(t) 的排序随 t 变**（反例：V_A ≡ 10 与 V_B ∈ {0,22} 各半：t=5 时 ṽ_A=5 > ṽ_B=2.5，
t=∞ 时 ṽ_B=11 > ṽ_A=10）。算法上无碍：每个格点 t 重排序 + 跑 DP；
结构上：**不存在对所有 t 一致的单一排序** ⇒ "单指标"表述不可恢复（§4 B7-neg）。

### 2.3 混合情形（chance 侧）：Ji 完全没有的一步，但恰好被 B2/B6 的单兑付结构接住

这是移植中**真正新的数学**，也是走得通的关键：

1. **截断折叠（B7c）**：`u_t := min{t,·}` 单调、u_t(0)=0（t ≥ 0）。B6 的 EU 折叠证明
   （逐点复合 + B2 按 sel 划分重排）对任意满足 u(0)=0 的单调 u 成立——**不需要凹性**
   （B6 陈述里的"凹"只服务于风险厌恶解释，不服务于折叠证明）。故
   `E_ch[min{t, Y}] = Σ_c Pr[sel=c]·E_M[min{t, V_c}] = Σ_c Pr[sel=c]·ṽ_c(t)`。
   全滑档项贡献 min{t,0}=0，自动消失。
2. **为什么 Choquet 非可加性不搅局（B7d）**：每个 ω 下只有**单个**不确定变量兑付，
   min{t,·} 是其单调变换 ⇒ B1 layer-cake 只需要生存函数 `M{V_c ≥ s}`（s ≤ t 段）+
   自对偶做 CDF 换算，次可加性根本没机会介入。单变量 + 单调变换 = Choquet 期望与
   分布式期望精确重合，这是有限重排，不是近似。
3. **chance 分布是混合 CDF（B7d 另一半）**：`Φ_c(y) := M{V_c ≤ y}` 由 B0 的单调性 +
   边界值是合法有限 CDF；`Φ = Σ_c π_c Φ_c + π_0·𝟙{y≥0}`（π_c = Pr[sel=c]，π_0 = 全滑档概率）
   是 CDF 的凸组合 = CDF。**方案 ↦ Y 的 chance 分布这张映射对首录概率向量 π_x 是仿射的**——
   这其实是 B2 的真实内容（B2 = 该仿射性的期望特例）。R-U 是分布层面的恒等式，
   对任何 CDF 成立 ⇒ 对 Φ 成立 ⇒ 与第 1 步的 E_ch 表达式对接（B7a + B7d 桥接）。

**主归约（B7）**：
```
max_{x∈可行集} CVaR_α^Ch(Y_x)
  = max_{t∈T} { (1/α)·max_x U(x; ṽ(t)) − ((1−α)/α)·t },
T = {0} ∪ ⋃_c supp(V_c),   ṽ_c(t) = E_M[min{t, V_c}]
```
内层 = 风险中性 BSAA（值 ṽ(t)，按 ṽ(t) 降序 + A3/配额 DP），外层 = 有限格点扫描。
复杂度 `O(|T|·(N log N + N·n))`；确定值 |T| ≤ N+1；原型层价值（7-15 个原型、小支撑）下 |T| 很小。
逐步假设标注：独立 Bernoulli 录取（仅 DP 精确性需要；归约与排序不需要）、有限支撑、
chain chance 公理（B2'）、v/V ≥ 0、t ≥ 0、可行集不依赖价值（基数/配额均满足）。

### 2.4 Q3：B6 是否降级 —— 是，精确表述如下

B6 原判断拆成两半，两半都变成定理候选：
- **负半（不可折叠，仍真）**：不存在单标量折叠 v̂_c 使 CVaR 最优化归为一次排序+DP。
  α-一致版反例（手算可验）：p_A = p_B = 1，V_A ≡ 10，V_B ∈ {0,22} 各半。
  顺序 (A,·)：Y ≡ 10；顺序 (B,·)：Y ∈ {0,22}。α=1 时 B 在前最优（E=11>10）；
  α ≤ 1/2 时 CVaR = 0 < 10，A 在前最优。最优排序随 α 翻转 ⇒ 无 α-无关标量。
  固定 α 版（不存在只依赖 (Φ_c, p_c) 的局部标量）：t* 全局耦合 ⇒ 加入第三候选可移动 t*
  从而翻转 A/B 相对序——**构造思路明确但未逐数验证，标为待验证猜想**（§4 B7-neg(ii)）。
- **正半（可解，新）**：即 B7 主归约。"不可线性折叠"≠"不可解"——
  这正是 Ji 论文的信息："CVaR 存在精确的非线性 → 一维线性族归约"，代价是一维外层搜索。

### 2.5 微例核算（归约公式 sanity check，手算）

单候选，p = 1/2，v = 10（确定值），Y ∈ {0, 10} 各半。
- α = 1/2：真值 CVaR = 最差一半平均 = 0。归约：`sup_{t≥0}{ 2·(p·min{t,10}) − t } = sup{ min{t,10} − t } = 0`（t∈[0,10] 取得）。✓
- α = 3/4：真值 = (4/3)·(0·(1/2) + 10·(1/4)) = 10/3。归约：`sup{ (4/3)·(min{t,10}/2) − t/3 }`，
  t=10 处 = 20/3 − 10/3 = 10/3，两侧斜率符号正确。✓

### 2.6 副产品：VaR 与机会目标（同一 mixture 仿射性的另两个开关）

- **B9（机会目标，直接线性）**：`Ch{Y ≥ v₀} = Σ_c π_c·M{V_c ≥ v₀} = U(x; q)`，
  `q_c := M{V_c ≥ v₀} ∈ [0,1]`——就是值为 q 的期望 BSAA，A2/A3 原样精确。
  （= B6 折叠取 u = 𝟙{·≥v₀}：单调、u(0)=0（v₀>0），凹性再次不需要。）
- **B8（VaR 最大化，水平集扫描）**：钉死有限支撑分位数约定后，
  `max_x VaR_α(Y_x) = max{ y ∈ ⋃supp : max_x U(x; q(y)) ≥ 1−α }`，`q_c(y) = M{V_c ≥ y}`
  ——每个 y 一次 DP，有限扫描精确。（全滑档项经自对偶换算已并入，推导时注意
  `Ch{Y<y}` 含 π_0·𝟙{y>0} 项，转成生存形式后恰好是 U(x;q(y))。）
- **仍开放**：ε-约束形式 `max E_ch[Y] s.t. Ch{Y ≥ v₀} ≥ β`。两个泛函都对 π_x 线性，
  λ-标量化（值 v̂_c + λq_c 的 DP 扫 λ）只能得支撑 Pareto 点，方案集离散有对偶间隙；
  精确解大概率要二维 DP（伪多项式）或证明间隙为零——**不在本次归约射程内，须如实声明**。

### 2.7 与 A5/A6（退档两阶段、v_dead）的兼容性

雷24 裁决后全滑档吸收态也兑付 v_dead ⇒ 终局事件对 (dead, c=1..N) 是**恰好 one-hot 的划分**，
把 V_dead 当第 N+1 个"候选"，B7b/B7c 逐字适用：截断实例的候选参数为
`ṽ_c(t) = (1−r_c)·E_M[min{t,V_c}] + r_c·E_M[min{t,V_dead}]`（截断作用在**终局值**上，
不是作用在折叠后的 ṽ_c 上——这个顺序不能反）。内层是 A5 型 BSAA（值 ṽ(t)），
继承 A5 的待证清单（展开式/交换/DP，v2 todo）。V_dead 为全体共享的不确定变量不碍事——
单兑付结构不变，B2 原话。附带修复一个退化：无 v_dead 时 α ≤ 全滑档概率下界会使一切方案
CVaR = 0（准则退化，见 §5 边界 3）；v_dead > 0 后下尾由保底价值托住，退化消失。

## 3. 卡点表（Ji-vs-BSAA 逐条判定）

| # | 差异点 | 判定 | 说明 / 所需新引理 |
|---|---|---|---|
| 1 | Ji：单次揭示+检查成本（Weitzman）；BSAA：Bernoulli 级联吸收、无成本 | **不阻断** | R-U + one-hot 两步完全不用揭示/成本结构；内层落回 BSAA 自己的 A2/A3 而非 Weitzman 指数。**内层保持性必须用 A2/A3 重证（= B7 主体），不可照抄 Ji 的指数唯一性论证**——但重证是直路（§2.2）。BSAA 无成本反而更干净；将来加线性申请成本，成本项像 Ji 一样留在期望层，不进 CVaR |
| 2 | 配额约束（冲稳保），Ji 无任何组合约束 | **不阻断归约；继承既有缺口** | 约束只碰 p-类计数、不碰价值 ⇒ 与截断交换，逐 t 的内层就是配额 BSAA。但配额 DP 精确性本身只有 814 实例数值验证、LEMMAS 无引理——**需 A3q**（与 CVaR 无关地本来就欠着）。CVaR 版的精确性 = A3q 的精确性，一荣俱荣 |
| 3 | 相关录取（单因子 Vasicek 等），Ji 假设独立 | **半阻断（与风险中性情形同位置断）** | 归约本体 distribution-free：mixture 公式对任意录取联合律成立，排序层由 A2 逐点性对任意律成立。断在内层选择：精确 DP 需独立（风险中性时已如此）。**且近似比不穿越归约**：内层 (1−1/e) 近似给 `(1−1/e)a − b ≥ (1−1/e)(a−b) ⟺ b ≤ 0`，t 项 b>0 时不成立 ⇒ 乘性保证被减号项破坏——与 Ji Thm 2（CVaR prophet 无常数比）同一气味。相关+CVaR 的近似理论 = 真开放，不许顺嘴声称 |
| 4 | Ji 的 A_i 是策略诱导的随机 one-hot；BSAA 的选择子是纯随机首录 | **不阻断（还更简单）** | 恒等式是逐实现的代数事实，与 A 是决策还是随机无关。BSAA 静态方案使 sup 交换退化为联合上确界的平凡交换，免去 Ji 自适应策略的论证负担 |
| 5 | 全滑档事件：A 全零（Ji 无此态） | **不阻断，需一行处理** | at-most-one-hot + t ≥ 0 + 值 ≥ 0 ⇒ 恒等式含全零分支成立（B7b）；t ≥ 0 是 WLOG（Y ≥ 0）。接 v_dead 扩展后升级为恰好 one-hot，处理反而消失 |
| 6 | 价值端是 Choquet/Liu 不确定变量，Ji 是普通概率分布 | **需新引理（B7c/B7d），可证性高** | Ji 零涉及非可加测度——这是移植的真新增量。被救回的原因：单兑付 ⇒ 每 ω 单变量 ⇒ 单调变换下 Choquet 期望 = 分布式期望（有限 layer-cake + 自对偶），mixture CDF 合法。**若未来价值端出现每 ω 多变量兑付（如打包志愿），此路当场断掉**——单兑付是承重墙，须写进假设 |

## 4. 新引理清单（精确陈述 + 可证性评估；建议入 LEMMAS v3 待办区，编号顺接 lit 文件建议的 B7）

**B7a（有限 R-U 恒等式）** 设 Φ 为 K 上有限支撑 CDF，支撑 ⊆ [0,∞)，0 < α ≤ 1。定义
`RU_α(Φ) := max_{t ∈ supp∪{0}} { t − (1/α)·Σ_y (t−y)⁺·Φ({y}) }`。则 RU_α(Φ) = Φ 的下尾
α-平均（分位数逐段定义），且 max 在 t = α-分位点取得；α=1 时 = 均值。
*可证性：高。凹分片线性函数的有限折点分析，纯代数；建议以 RU 为定义、尾平均为派生引理，
把分位数约定（≥/> 边界）钉死在陈述里。*

**B7b（at-most-one-hot 截断恒等式）** t ≥ 0，x_i ≥ 0，A ∈ {0,1}^N 且 Σ A_i ≤ 1，则
`min{t, Σ_i A_i x_i} = Σ_i A_i·min{t, x_i}`。
*可证性：极高（两分支各一行）。*

**B7c（截断折叠 = B6 的非凹推广）** B6 陈述中把"u 单调凹"放宽为"u 单调、u(0)=0"，
结论 `E_ch[u(Y)] = Σ_c Pr[sel=c]·E[u∘V_c]` 不变。特例 u = min{t,·}（t≥0）与 u = 𝟙{·≥v₀}。
*可证性：高——B6 的证明（B2 划分重排 + 逐点复合）本来就没用凹性，属陈述放宽而非新证明。*

**B7d（chance 分布 = 混合 CDF；单调变换的 Choquet-分布一致性）**
(i) `Φ_c(y) := M{V_c ≤ y}` 是合法有限 CDF（B0 单调性+边界值）；
`Ch{Y ≤ y} = Σ_c π_c Φ_c(y) + π_0·𝟙{y ≥ 0}`（chain 公理 B2' 下的有限重排）。
(ii) 对单调不减 f ≥ 0：`E_M[f(V_c)] = Σ_j f(y_j)·(Φ_c 增量)_j`（layer-cake + 自对偶）。
*可证性：高。与 B1/B2 同一工具箱；(ii) 的 ≥/< 边界换算是唯一细心点。*

**B7（主定理：CVaR 一维线性族归约）** 独立 Bernoulli 录取 + 有限支撑不确定值 + chain chance
公理下，对任意价值无关的可行集（基数/配额）：
`max_x CVaR_α^Ch(Y_x) = max_{t∈T} { (1/α)·max_x U(x; ṽ(t)) − ((1−α)/α)·t }`，
`T = {0} ∪ ⋃_c supp(V_c)`，`ṽ_c(t) = E_M[min{t,V_c}]`；内层由 ṽ(t) 降序 + DP 精确求解；
外层格点精确性由"格胞内逐方案仿射 ⇒ max_x 胞内凸 ⇒ 端点取最值"论证（**不是**"凹函数折点"论证）。
对固定方案同式给出 CVaR 精确计算。
*可证性：高，依赖 B7a-d + A1-A3（+A3q 若带配额）。全链有限代数，符合 LEMMAS 的
零实分析约束，α ∈ K 只需域除法。*

**B7e（确定值排序的全准则提升）** 值确定时，v 降序对固定 S 在**任意录取联合分布**与
**任意单调律不变准则**（CVaR/VaR/distortion/EU）下同时最优。
*可证性：极高——A2 逐点占优 + 准则单调性，两行。这是"排序层免费、B6 障碍在选择与折叠层"的定理化。*

**B7-neg（单标量折叠不可能）** (i) α-一致版：存在实例（§2.4，p≡1 双候选）使 CVaR 最优排序
随 α 翻转 ⇒ 不存在 α-无关的单标量折叠。*可证性：极高，反例已手算。*
(ii) 固定 α 版：不存在只依赖 (Φ_c, p_c) 的局部标量在固定 α 下恒给出最优排序。
*可证性：中高——构造思路（第三候选移动 t* 翻转 A/B 序）明确，但本次未逐数验证；
入 LEMMAS 前须先数值构造一个具体三候选实例（后续小任务，非本文档范围）。在验证前只许称猜想。*

**B8（VaR 水平集归约）/ B9（机会目标折叠）** 如 §2.6 陈述。
*可证性：B9 高（B7c 特例）；B8 中高（分位数边界约定是全部难度所在）。*

**A3q（配额 DP 精确性）** 独立缺口，CVaR 无关但被 B7 继承；无它则 B7 的配额版只到
"数值验证"级。*可证性：中高（A3 归纳加一维状态），工作量与 A3 相当。*

**诚实边界（缺一不可，防超卖）**：

   有意义的域是 α > π_0 或接 A5/雷24 的 v_dead 扩展（§2.7）。产品端若报告 CVaR 必须带此脚注。

   产品解释话术不得再用"每个志愿一个分、排个序"来描述 CVaR 模式。

   A3q 未证则配额版 B7 只有数值级保证。
