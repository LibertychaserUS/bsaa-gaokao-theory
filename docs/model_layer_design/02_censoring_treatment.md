## 0. 核心立场

D 区的每一个 censor 标记（`head_aggregate` / `le` / `missing` / 征集轮语义）都是"**信息被隐藏的坐标**"，
不是"脏数据"。清洗层的职责已经完成：诚实标注了"哪里看不见"。M 区的职责是**不把"看不见"悄悄变成
"看见了但恰好是个整数"**——这正是 Oliver 强调的"哨兵的位置是被隐藏的"。

四类隐藏信息在统计性质上并不同质，必须区分对待：

1. **值删失（value censoring）**：真值存在，但只知道其落在某界内（T1 `le`、T2 `head_aggregate` 的顶部区间）。
   → 用删失似然，不用点估计。
2. **缺失机制歧义（missingness ambiguity）**：观测值缺失本身可能有两种完全不同的生成机制
   （T1 `missing`：投档未满 vs 真缺失），且两种机制对应完全相反的业务含义。
   → 先用 D 区旁证信号做机制归类，再分流处理，禁止统一 impute。
3. **总体选择性截断（population-shift censoring）**：观测值本身精确，但其所指代的总体被截断/换了
   （征集轮 min_rank 描述的是"落选后二次报名的候选子群"，非全体候选）。
   → 禁止跨总体池化，只能作为哨兵特征或独立分层使用。
4. （交叉情形，本文末单独一段）T2 顶部聚合与 T1 `le` 会在同一批考生（顶尖分数段申报顶尖院校）身上叠加，
   造成误差的"高关注度聚集"——精度损失最集中的地方恰是最受关注的查询。

## 2. 逐行展开

### 2.1 T2 head_aggregate：高分候选查询的位次不确定性

清洗规范 v1.5 的统一锚点裁决（`table_top+1` 哨兵）已经把"该池顶部未逐分公布的全部人数"正确地
聚合进一条哨兵行，这是**清洗侧的诚实处理**——它没有编造逐分分布。但这条哨兵行本身携带的信息量
只是"总人数=gap"，不含分布形状。M 区继承时必须同样诚实：**不能因为清洗侧已经把哨兵"钉死"在
一个分数点上，就误以为不确定性已经被消除了**——哨兵钉住的是"这一段有多少人"，没有钉住"这一段内部
谁比谁靠前"。

实证数据显示（`data_cleaning_spec_shandong_v1.md` 附录 v1.1）：主科池（全体/物理/化学/多数生物）
的聚合区间通常极窄（甚至零宽，只在表格最顶端一行本身发生"表内无更高分行、但 cum>count"），
而副科池（政/史/地、2024 生物）聚合区间可达 15+ 分、跨多个分数刻度。这意味着：

- 对报考主科类顶尖专业的极端高分考生，位次不确定性通常很小（gap 本身量级小，且区间窄）；
- 对副科（史/地/政）方向的顶尖考生，位次不确定性可能覆盖相当大的名次区间，而这批考生恰好是
  文科方向清华北大等顶校专业的主力申报人群——**精度损失与查询关注度在这里发生了聚集**（见 §3）。

M 区构造建议：
- **短期**：对落入聚合段的候选，位次输出为区间 `[1, gap]`，前端/报告层禁止展示为单一数字；
  若下游算法（DP/排序）必须要一个标量 p_i，用区间上下界各算一次 p_i，取值范围作为该候选该项目的
  "p_i 置信带"，而不是用区间中点悄悄退化成点估计。
- **中期**（对应研究方向 §4 中期"EVT 头部分支"）：对聚合区间内的密度用广义 Pareto 分布尾部拟合
  （需要额外假设声明：尾部形状参数从哪些年份/池的数据借力估计），把区间估计收紧为一个"声明了假设"
  的分布，而非无信息假设下的均匀分布——两种做法必须都留痕（TR6 消融），不能只留一种就当结论。

### 2.2 T1 `le`：左删失阈值——绝不能把上界当成实现值

`前50`/`前50名` 这类记录，语言学上是"截断表述"，统计学上是标准的**左删失（left-censored）观测**：
真值 Y 满足 Y ≤ 50，Y 的具体值未知。这是幸存者偏差以外的另一种"最容易被无声吞掉精度"的位点——
因为它长得像一个正常整数（50），非常容易在下游被 `pd.to_numeric` 或特征拼接时当作精确值直接使用，
而清洗规范的 R3 已经明确禁止这种静默 coerce，M 区必须在契约层继续把这条防线延伸到统计模型内部：

- **拟合阈值分布 G_p 时**：该样本对似然函数的贡献是 `L_i = G_p(50; θ)`（累积概率，而非密度）；
  这是生存分析里标准的左删失似然写法，MLE/贝叶斯后验都可直接扩展（似然乘积中该项换成 CDF 而非 pdf）。
  **不要丢弃**——丢弃会损失"这个项目录取门槛很紧"这一强信息，且清洗侧统计（G5 黄金断言）已把这类行
  的计数当作数据完整性锚点，丢弃会破坏可复算性对齐。
- **对该项目本身查询 p_i 时**：因为 θ 已经在删失似然下正确估计，模型给出的隐含阈值分布本身会比 50
  更靠前（更严格），不需要再对单个查询做二次修正——但产品侧措辞必须提示"该校该专业历史上出现过
  阈值删失记录，实际门槛可能显著低于历史展示的名义上界"。

**若误当精确值**：把 50 直接塞进普通 MLE/点残差，等价于假设"清华这个专业恰好卡在第 50 名"，
这会系统性地**高估**该项目的真实录取位次数值（即低估其真实选拔严格度），因为真值只会 ≤50、
往往远小于 50（越顶尖的项目/年份，真实截断点相对报告上界的收缩比例越大，但具体收缩量级
无法从本表单独估计，需要跨年/跨校的删失似然联合拟合才能给出）。下游后果：对排名接近 50
名的边缘考生，会被系统性地给出**虚高的 p_i**——这是最危险的一类偏差方向，因为它会诱导考生
把清华这类超顶尖志愿当作"有一定把握"的选项去冲，而真实把握可能远低于展示值。

### 2.3 T1 `missing`：先分流，再各自处理，禁止统一 impute

规范 R3 把 `missing` 定义为"空串/None → NULL"，但没有（也不该在清洗层）区分背后的生成机制——
这正是清洗层"保留优先于修复"的正确边界：机制判别需要跨表信号，属于 M 区的转译工作，不是
逐行清洗规则该做的事。

**区分信号**：
1. **征集表哨兵**（首选信号，与雷 8 幸存者偏差解法复用同一张表）：以 `(school_code, major_code)`
   为键，查该项目当年 T3（round=2/3 剩余计划表）是否出现、且 `plan_count > 0`。命中
   → 该项目当年 round1 未招满，round1 缺失的 min_rank 是因为"没有产生阈值这件事"，
   不是记录丢失；判定为 **3a 投档未满**。
2. **批次控制线交叉验证**（辅助信号，非独立判据——T1 本身无分数列/投出数列，雷 20 已明确
   "投档表无分数列、无投出数列"，故只能做定性一致性检查而非定量核验）：若该项目所在批次
   当年控制线（T4）划定的报考基数远超其计划数，而该项目仍缺失位次，"投档未满"判定的可信度
   应降低（供给远小于需求的批次里出现未招满，更可能是数据记录问题而非真的没人报），
   此信号只降级/升级置信度，不单独作为判据。
3. 若信号 1 未命中（且信号 2 未提示矛盾）→ 判定为 **3b 真缺失/机制不明**，进保守分支
   （见处理表 3b 行）。

**若统一 impute（不分流）**：
- 若把 missing 当 0（不可能的极端值，但历史上常见的"NaN→0"事故）：会捏造出一个不存在的
  "极端严格阈值"，对该项目产生虚假的极低 p_i——完全颠倒了真实方向（真实很可能是极高 p_i，
  因为多半是投档未满）。
- 若用全局均值/中位数 impute：对 3a（投档未满，真实 p_i 应接近 1）会**系统性低估** p_i，
  让系统"漏推荐"本该是最保险的保底选项——这是一种隐蔽的、不易被察觉的机会成本型偏差，
  因为它不会报错、只会让候选人错过一个原本很安全的志愿。
- 对 3b（真缺失）用同权重的均值 impute，则是把"完全不知道"伪装成"和别的项目差不多"，
  向模型注入了不存在的确定性，压低了报告中本该体现的不确定性宽度。

### 2.4 征集轮 min_rank：数值可能精确，总体已经被换掉

这一行的隐藏信息性质和前三行不同，值得单独强调，因为它最容易被漏判为"没有删失、数值本身是
`exact`，可以直接用"。规范里 T1 的 round 列本身就允许 round=2/3 各自独立走 R3 三态判定
（即 round2 的 min_rank 完全可能是 `exact`，没有任何 le/missing 标记）。**但"没有值删失"
不等于"可以池化"**——第 1 次投档的候选池近似"全体符合条件的报考人"，第 2/3 次投档的候选池
是"第 1 次没有被这个专业/没有被心仪专业录取、回来二次报名的人"，这是一个**由不可观测机制
决定的自选择子群**，而这个自选择机制本身（谁会去征集、为什么去征集）D 区完全没有记录、
甚至征集意愿本身也不是随机的。

这意味着：即便 round2 某专业的 min_rank=45000（一个干净的、无删失标记的整数），它回答的问题
是"在'第 1 次落选/未确认'这个被截断的子总体里，最低录取位次是多少"，而不是"在全体报考人里，
这个专业本轮的录取阈值是多少"——**两个问题的答案不能互相替代，也不能简单平均**。

**能否进入同一程序的阈值史**：不能直接进入（禁止池化进同一 G_p 似然）。可以进入的是：
- 作为**存在性哨兵**（0/1 二元特征），复用于 §2.3 的 missing 机制判别；
- 作为**征集/专科支线**独立分层模型的观测（若产品需要覆盖征集志愿场景，另起一条与主线
  参数不共享的拟合，允许日后作为 v2 建设项）；
- 作为**report-only 描述性对照**，用于人工核查"这两轮确实是不同总体"（而不是拿来训练）。

**若误当同分布重复观测处理**（即把 round1+round2+round3 的 min_rank 混进同一个训练样本池
当作"同一项目多次独立观测，多几条数据总是好的"）：这不是简单的方向性偏差，而是**污染共享
参数的选择性偏差**——由于是否进入 round2/3 本身取决于 round1 结果（成绩不够好/志愿填报策略），
混入的数据点在统计意义上违反了"独立同分布抽样"假设，会让全局拟合的方差结构失真，且失真方向
因项目冷热程度不同而不同（无法给出统一方向），但**必然存在且必然被低估**（因为常规 MLE
不会自动察觉训练数据里混了两种生成机制）。这是四个位点里唯一一个"偏差方向不确定但确定性
本身被侵蚀"的情形，因此处理原则是硬性分层隔离，而非事后修正。

---

## 3. 交叉叠加：顶部聚合 × 左删失，精度损失聚集在最受关注的查询上

T2 的头部聚合主要打击"分数段极端靠前"的考生（尤其副科池），T1 的 `le` 删失主要打击"最顶尖、
最热门的项目"（清华北大等极端热门专业普遍出现"前 N 名"式的门槛表述）。这两类考生-项目组合
高度重叠：**恰好是分数最高的一批考生，去查询恰好门槛表述被删失得最厉害的那批项目**。

结果是：系统精度最薄弱的地方，正好是流量/关注度最集中、决策后果最重的地方（"我能不能上清华"
这类查询）。这不是随机噪声均匀分布在系统各处，而是一个**结构性的、可预见的高风险象限**。
M 区的设计含义：
- 产品侧对这一象限的输出必须默认带更宽的不确定性提示（而不是和其他项目用同一套置信区间宽度展示）；
- C 门评估协议（C6 区间覆盖率检查）应该单列这个象限（"顶尖分数段 × 顶尖院校"子集）的覆盖率，
  而不是只看全局平均覆盖率——全局平均很容易被大量"中等分数、中等热度"的项目稀释，掩盖掉这个
  小而关键子集的失准。

## 4. 与 C 门/TR 门的映射汇总（便于门禁落地时直接引用）

- **C3（已立法）** 需要在实现层显式扩展覆盖：本备忘 3a/3b 的 reclassify 结果、征集轮数据的
  round 掩码排除，都应视为 C3"censor 行不进点估计残差池"这条硬门的自然延伸，而不是新开一条门
  （避免门禁膨胀，但实现说明文档要写清覆盖范围）。
- **C1（无泄漏审计）** 需要新增一类可审计标签：**回填/近似来源标签**（backfilled / control-line-proxy /
  round-derived-sentinel），逐列发布日期审计的同一张表里追加"数据来源类型"列，防止这些非直接观测值
  被误当一等观测特征使用。
- **C6（区间覆盖率）** 需要按"顶部聚合命中" × "le 删失命中"两个二元标志做子集分层报告（见 §3），
  不能只看全局覆盖率。
- **TR1（构造期物理隔离）** 需要把"round 掩码"和"聚合段掩码"纳入同一套构造期防呆机制——
  训练数据加载 API 层面就不给普通拟合路径提供 round≠1 的 min_rank 原始数值、不给普通残差路径
  提供聚合段候选的位次点值，而不是靠运行时 if 判断（TR1 的核心精神是"物理拿不到"而非"事后过滤"）。
- **TR6（消融留痕）** 需要至少保留两组对照：①3a/3b 判定边界（宽松信号 vs 严格信号）的两版结果；
  ②T2 顶部聚合的"均匀假设区间估计" vs "EVT 尾部估计"两版结果——两者都是本备忘中标注为
  "需要显式声明假设"的建模选择，属于最该留痕对照的地方。

## 5. 一句话总结

四个位点里，前两个（T2 聚合、T1 `le`）是标准的**值删失**，正确工具是删失似然/区间估计；
第三个（T1 `missing`）不是删失而是**缺失机制的二值分类问题**，正确工具是先用征集表旁证分流、
再分别处理，而不是统一插值；第四个（征集轮）不是删失而是**总体被换掉**，正确工具是分层隔离
而不是池化。四者共同的纪律只有一条：**任何时候界/分布/分类标签都不能在中间某一步被悄悄压扁成
一个看起来正常的数字**——一旦压扁，偏差就会沿着"这个数字后来被用在哪"一路传导下去，而且传导路径
往往正好是决策后果最重的那条路径（§3）。
