# 聊城不确定性系统年会投稿结合策略

> 目标：把 GSIO（Gaokao Sequential Inference & Optimization）志愿填报框架与“不确定性系统”研究范式对接，使论文既能服务考生决策，又能进入不确定性系统/不确定规划的学术语境。

---

## 1. 核心映射：录取阈值是不确定变量

高考志愿填报的本质困难在于 **录取位次/分数线在投档前不可确知**。在 GSIO 中，这一困难可形式化为：

- 设考生真实位次为 \(r_0\)，院校专业组 \(j\) 的录取阈值为随机变量 \(\tilde{R}_j\)。
- 录取事件为 \(\{r_0 \le \tilde{R}_j\}\)；录取概率为 \(P(r_0 \le \tilde{R}_j \mid \mathcal{D})\)，其中 \(\mathcal{D}\) 为历史一分一段表与招生计划。
- 由于招生计划、报考热度、考生偏好结构都会扰动阈值，\(\tilde{R}_j\) 不是单一概率分布，而是 **经验不确定分布**（empirical uncertainty distribution）或 **基于历史数据的不确定测度**。

> 术语边界：若使用 Liu 不确定性理论，应避免把 \(\tilde{R}_j\) 说成“概率”，而称“不确定变量”及其“不确定分布” \( \Phi_j(x) = \mathcal{M}\{ \tilde{R}_j \le x \} \)。若面向概率统计背景更浓的会议，可保留“经验分布 + Bootstrap”表述，但需在引言说明：本研究把录取阈值视为 **由有限历史数据生成的不确定量**。

## 2. GSIO 与不确定规划的对接

GSIO 的优化目标（最大化录取概率与院校满意度的综合期望）可写成不确定规划形式：

```
maximize  E_ξ[ U(x, ξ) ]
subject to  x ∈ X_admission   （院校专业组集合、平行志愿规则、考生偏好约束）
            risk constraints    （掉档风险、专业调剂风险）
```

其中：

- \(x\)：志愿表（顺序决策变量）。
- \(\xi\)：由录取阈值、考生分数波动、招生计划变化组成的 **不确定向量**。
- \(U(x, \xi)\)：效用函数，包含“录取到第 \(k\) 志愿的满意度”与“未录取的惩罚”。

与经典不确定规划的区别：

| 特征 | 经典不确定规划 | GSIO 志愿填报 |
|------|----------------|---------------|
| 决策阶段 | 静态/多阶段 | 顺序投档（一次投档、平行志愿） |
| 不确定源 | 外生随机变量 | 历史数据稀缺导致的 **数据驱动不确定** |
| 约束 | 资源/能力约束 | 政策规则约束（志愿数、调剂、征集） |
| 求解 | 遗传算法/场景法 | 顺序蒙特卡洛 + 动态规划 + 贝叶斯更新 |

因此论文可定位为：

> **数据驱动的顺序不确定决策问题**：在投档规则（一次投档、分数优先）下，利用有限历史数据对录取阈值进行不确定建模，并求近似最优志愿序列。

## 3. Bootstrap：不确定模拟的天然包装

项目已实现的 Bootstrap 验证可重新表述为 **不确定模拟**（uncertainty simulation）：

1. 从历史一分一段表中重采样，得到多个“平行世界”的录取阈值样本。
2. 对每个样本运行 GSIO 算法，得到该世界下的推荐志愿表。
3. 汇总录取结果、满意度、风险指标，形成 **期望效用与风险** 的估计。

在不确定性理论年会语境下，可强调：

- Bootstrap 不是传统 Monte Carlo 对已知分布的采样，而是 **对经验不确定分布的逆变换采样**。
- 它天然对应 Liu 不确定性理论中的 **不确定模拟**：通过不确定分布的反函数生成样本。
- 由于历史数据有限，Bootstrap 样本既体现了 **随机性**，也体现了 **认知不确定性**（epistemic uncertainty）。

- 选项 A（偏不确定规划）：**《基于数据驱动不确定规划的平行志愿顺序决策方法》**

推荐：若年会主题强调“不确定性系统”，用 **选项 B**；若审稿人更偏运筹优化，用 **选项 C**。

### 4.2 摘要 wording 示例

> 高考志愿填报面临招生计划、报考热度与录取阈值的多重不确定性。本文提出 GSIO 框架，将平行志愿投档规则建模为顺序决策过程，基于历史一分一段数据构造录取阈值的经验不确定分布，并通过 Bootstrap 不确定模拟评估志愿方案的期望效用与风险。实验表明，该方法在真实数据集上较传统“冲稳保”策略具有更高的录取概率与满意度。

## 5. 需要注意的术语边界

| 概率论语境 | 不确定性理论语境 | 建议使用场景 |
|------------|------------------|--------------|
| 概率 / 随机变量 | 不确定变量 / 不确定分布 | 若引用 Liu 理论，必须换术语 |
| 期望值 | 不确定期望值 | 不确定性理论年会 |
| 置信区间 | 不确定置信区间 | 避免与频率学派冲突 |
| Bootstrap 采样 | 不确定模拟 / 经验不确定分布采样 | 提升理论一致性 |
| 风险 | 机会约束 / 不确定测度 | 优化领域通用 |

建议：在论文中先给出 **“录取阈值是不确定的”** 这一中性表述，再根据目标会议在方法论小节选择概率或不确定性理论的术语体系。若同时投概率统计和不确定性系统两个会，可准备两个术语版本，但数学模型保持一致。

## 6. 与聊城不确定性系统年会的具体对接点

根据年会通常关注的研究方向，可突出以下创新点：

1. **数据稀缺下的不确定建模**：高考历史数据有限，传统大样本统计假设不成立，适合用不确定性理论研究小样本不确定。
2. **顺序决策与一次投档规则**：平行志愿不是静态选择，而是“顺序吸收”机制，与排队论、随机动态规划有天然联系。
3. **人机协同决策**：GSIO 不仅给出推荐，还通过解释录取概率/风险，帮助考生在不确定环境中做出更理性的选择。
4. **可解释性与公平性**：不同分数段考生的不确定感知不同，可延伸为“不确定性厌恶”与“教育公平”议题。
