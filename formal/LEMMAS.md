# BSAA × 不确定性理论 混合模型 — Lean 4 形式化规格 (v1, 2026-07-15)

目标：为"录取端=概率（频率数据），价值端=不确定变量（专家信度）"的混合志愿模型，
形式化证明其核心引理链。**全部限定在有限支撑上，纯代数（任意 LinearOrderedField 或 ℚ），
不使用实分析/测度论**，以保证 Lean 4 可行性。

约定：候选集 `Fin N`；值 `v : Fin N → K`（`0 ≤ v`）；概率 `p : Fin N → K`（`0 ≤ p i ≤ 1`）。
方案 = 无重复列表 `x : List (Fin N)`。效用
`U(x) = Σ_k v(x_k) · p(x_k) · Π_{j<k} (1 - p(x_j))`。

## Part A — 确定性核

**A1（首次成功分布）** 定义有限乘积概率空间 Ω = (Fin N → Bool) 带独立 Bernoulli(p_i) 权重
`w(ω) = Π_i (if ω i then p i else 1 - p i)`。定义 `firstAdmitted x ω : Option (Fin N)` 为 x 中第一个
被 ω 录取的元素。证明：
(a) `Σ_ω w ω = 1`；
(b) `Pr[firstAdmitted x ω = some (x k)] = p (x k) · Π_{j<k} (1 - p (x j))`；
(c) `U(x) = Σ_ω w ω · payoff x ω`，其中 `payoff x ω = v c`（若 firstAdmitted = some c）否则 0。

**A2（逐点排序定理，distribution-free Value-Index）** 对任意固定 ω 与底集相同的两个列表：
(a) `payoff x ω ≤ maxOver (S ∩ admitted ω) v`（空集时 = 0）；
(b) 若 x 按 v 降序，则取等。
推论（关键）：对**任意** ω 上的权重分布（不要求独立、不要求乘积形式），
v 降序排列在同底集的所有排列中最大化期望 payoff。

**A3（DP 精确性）** 设全体候选按 v 降序排成列表 L。定义
`g : ℕ → ℕ → K`，`g i k = 0`（i ≥ N 或 k = 0），否则
`g i k = max (g (i+1) k) (p (L i) * v (L i) + (1 - p (L i)) * g (i+1) (k-1))`。
证明：`g 0 n = max { U(S 按 v 降序) : S ⊆ 候选, |S| ≤ n }`。
（对 i 逆向归纳；需要引理：v 降序前缀下 U 的 Horner 分解
`U(c :: rest) = p c * v c + (1 - p c) * U rest`。）

**A4（Fréchet 安全界，选做）** 对任意有限联合分布（边缘为 p，不要求独立）：
(a) `Pr[至少一个录取] ≥ max_{j∈S} p j`（单调性一行）；
(b) 可达性：构造共单调耦合（单一均匀公共因子 U，录取 j ⟺ U ≤ p j 的有限栅格版）使 (a) 取等。

## Part B — 不确定性侧（Liu 公理，有限版）

**B0（结构）** `structure UncertainSpace (Γ : Type) [Fintype Γ] (K)` 携带
`M : Finset Γ → K` 满足：`M univ = 1`；`M ∅ = 0`；对偶 `M A + M Aᶜ = 1`；
单调 `A ⊆ B → M A ≤ M B`；次可加 `M (A ∪ B) ≤ M A + M B`。
（B5 之前不需要乘积公理。）

**B1（有限 Choquet 期望）** 对 `τ : Γ → K`，`0 ≤ τ`，取值 `t₁ > t₂ > … > t_r ≥ 0`：
`E[τ] := Σ_i (t_i - t_{i+1}) · M {γ : τ γ ≥ t_i}`（约定 t_{r+1} = 0）。
证明：(a) `E[const c] = c`；(b) `E[a • τ] = a * E[τ]`（a ≥ 0）；(c) 单调：`τ ≤ σ → E[τ] ≤ E[σ]`。

**B2（混合归约主引理 ★）** 设 (Ω, w) 为有限概率空间，`sel : Ω → Option (Fin N)`，
每个候选的价值为不确定变量 `V : Fin N → Γ → K`（≥0，有限支撑）。
定义混合支付 `Y ω γ = V c γ`（若 sel ω = some c）否则 0，
以及 chance 期望 `E_ch[Y] := Σ_ω w ω · E[Y ω ·]`。证明：
`E_ch[Y] = Σ_c Pr[sel = some c] · E[V c]`。
**注意：不需要 V c 之间的任何独立性假设**（每个 ω 只有单个不确定变量兑付，
证明是按 sel 取值划分 Ω 的有限重排）。

**B3（优化转移）** 组合 A1+A2+A3+B2：令 `v̂ c := E[V c]`。则
(a) 方案 x 的 chance 期望 = 确定性 `U(x)` 取 `v = v̂`；
(b) chance 期望最优的 (S, σ) = 确定性 BSAA 在 v̂ 下的最优，
排序按 v̂ 降序、选择由 A3 的 DP 精确给出。

**B4（共单调可加性，选做但重要）** 若 `τ σ : Γ → K` 共单调
（`∀ γ γ', (τ γ - τ γ') * (σ γ - σ γ') ≥ 0`），则 `E[τ + σ] = E[τ] + E[σ]`
对任意满足 B0 的 M 成立（有限 Choquet 的经典共单调可加性）。
用途：多原型线性价值 `V c = Σ_m π_m · U_{c,m}`，专家分共单调时线性折叠仍成立。

**B5（独立线性性，stretch）** 在带乘积公理的乘积不确定空间上，
独立 τ, σ 且 a,b ≥ 0 ⟹ `E[a•τ + b•σ] = a E[τ] + b E[σ]`。（可延后。）

## v2 待办（**本轮勿实现**，lean-prover 忽略本节）

**A5（退档两阶段吸收，2026-07-15 深夜设计）** 每候选带 (p_c, r_c, v_c)：以 1-p_c 存活继续、
p_c(1-r_c) 录取得 v_c、p_c·r_c 退档得 v_dead（过程终止）。则
`U(x) = Σ_k Π_{j<k}(1-p_j) · p_k · ṽ_k`，其中 `ṽ_c := (1-r_c)·v_c + r_c·v_dead`。
待证：(a) 该展开式；(b) 交换论证对 ṽ 成立（相邻交换差 = P0·p_a·p_b·(ṽ_a-ṽ_b)）⇒ 按 ṽ 降序最优；
(c) DP 对 (p, ṽ) 原样精确。注：A2 的 distribution-free 逐点性在此扩展下不保留（回到独立/交换论证），
需在陈述中显式声明。与 B2 组合：v_c 不确定时 ṽ_c 的期望 = (1-r_c)·E[v_c] + r_c·v_dead，折叠依旧成立。

**A6（调剂 flag 逐点分离定理，v2）** 每候选带决策变量 a_c ∈ {0,1}（服从调剂与否），
影响其两阶段参数：ṽ_c(a) = (1-r_c(a))·v_c(a) + r_c(a)·v_dead，其中
a=1: r≈0、v(1)=q_c·v_adj,c+(1-q_c)·v_c（组内调剂着陆混合价值）；
a=0: r(0)=q_c（够组线不够专业线概率）、v(0)=v_c。
待证：因 U 对每个 ṽ_c 单调线性（系数 ≥0），最优 flag 逐点分离：
a_c* = argmax_a ṽ_c(a)（等价判据：a*=1 ⟺ E[v_adj,c] ≥ v_dead），
且 max_{S,σ,a} U = max_{S,σ} U(·; ṽ*)，ṽ*_c := max_a ṽ_c(a)。零组合爆炸，sort+DP 原样。
注：v_dead 可为全体候选共享的不确定变量（学生信度）——B2 单兑付结构不受影响，
E[ṽ_c] = (1-r)E[v_c] + r·E[v_dead] 照常折叠。专业+院校模式（无调剂概念）下 a 退化、r 塌缩为硬项风险。

**B6（期望效用型风险厌恶折叠，v2）** 设 u : K → K 单调凹、u(0)=0。则
`E_ch[u(Y)] = Σ_c Pr[sel=some c] · E[u ∘ V c]`（混合仍是"单变量兑付"，逐点复合不破坏结构）。
⇒ 风险厌恶的 vNM/期望效用形式**免费兼容**：v̂_c := E[u(V c)]，排序/DP/全部定理照用。
**边界声明（2026-07-16 精化，见下 v3 待办 B7 系列）**：可折叠准则精确刻画 = "对外层概率混合线性"
（任意逐点变换的期望都行）。CVaR/VaR/机会目标**曾**列为"不可分离开放问题"——现改判为
**无单标量折叠（B7-neg 仍真）但存在精确一维线性族归约（B7/B8/B9）**，详见
`docs/model_layer_design/b6_cvar_feasibility.md`（Ji one-hot + R-U 归约可行性评估，纸上推导已核）。

## v3 待办（2026-07-16 追加；B6 CVaR 攻坚产出，主循环核验后登记，尚未 Lean 实现）

依据 `docs/model_layer_design/b6_cvar_feasibility.md`（微例核算 + R-U/one-hot 恒等式已手算核验）。

**B7a（有限 R-U 恒等式）** 有限支撑 CDF Φ（支撑⊆[0,∞)）、0<α≤1：
`RU_α(Φ) := max_{t∈supp∪{0}}{t − (1/α)Σ_y(t−y)⁺Φ({y})}` = Φ 下尾 α-平均，max 在 α-分位点取得。可证性高。
**B7b（at-most-one-hot 截断恒等式）** t≥0、x_i≥0、ΣA_i≤1：`min{t,ΣA_i x_i}=ΣA_i min{t,x_i}`。可证性极高。
**B7c（截断折叠=B6 非凹推广）** B6 的"单调凹"放宽为"单调、u(0)=0"，结论不变；特例 u=min{t,·}、u=𝟙{·≥v₀}。可证性高。
**B7d（chance 分布=混合 CDF）** Φ_c(y):=M{V_c≤y} 合法 CDF；Ch{Y≤y}=Σπ_cΦ_c+π_0𝟙{y≥0} 是 CDF 凸组合；单调变换下 Choquet 期望=分布式期望。可证性高。
**B7（主定理：CVaR 一维线性族归约）** 独立 Bernoulli 录取 + 有限支撑不确定值 + chain 公理 + 价值无关可行集：
`max_x CVaR_α^Ch(Y_x) = max_{t∈T}{(1/α)max_x U(x;ṽ(t)) − ((1−α)/α)t}`，
T={0}∪⋃supp(V_c)，ṽ_c(t)=E_M[min{t,V_c}]；内层 ṽ(t)降序+DP，外层格胞内逐方案仿射⇒max_x 胞内凸⇒端点取最值。可证性高（依赖 B7a-d+A1-A3，配额版需 A3q）。
**B7e（确定值排序全准则提升）** 值确定时 v 降序对任意录取联合分布 + 任意单调律不变准则（CVaR/VaR/distortion/EU）同时最优。可证性极高（A2 逐点占优两行）。
**B7-neg（单标量折叠不可能）** (i) α-一致版：反例已手算（p≡1 双候选 V_A≡10/V_B∈{0,22}，最优排序随 α 翻转）。(ii) 固定-α 版：构造思路明确但**未数值验证，只许称猜想**——入 LEMMAS 前须先构造具体三候选实例。
**B8（VaR 水平集归约）/ B9（机会目标折叠）** 见 b6_cvar_feasibility §2.6；B9 高、B8 中高（分位数边界约定是全部难度）。
**A3q（配额 DP 精确性）** 独立缺口，CVaR 无关但被 B7 继承；无它则配额版 B7 只到数值验证级。

**残留真开放件**：ε-约束机会形式（max E s.t. Ch≥β，双目标标量化有对偶间隙）；相关录取下的近似理论（近似比不穿越归约，与 Ji Thm 2 同气味）。
**承重前提**：单兑付结构（每 ω 单变量兑付）是承重墙——多变量兑付（打包志愿）则此路断。
